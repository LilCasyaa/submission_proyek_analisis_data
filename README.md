# Proyek Analisis Data: E-Commerce Dataset

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis data transaksi e-commerce guna mengidentifikasi kategori produk terlaris, penghasil revenue terbesar, serta melihat pengaruh waktu pengiriman terhadap tingkat kepuasan pelanggan (review score).
